# TrueWords Review PWA 2026

Öffentliche statische Prüfoberfläche für die manuelle Segmentierung eines privaten Telegram-Chats.

## Datenschutz

- Keine Chatdatei ist im Repository enthalten.
- Der Chat wird ausschließlich lokal im Browser geöffnet.
- Es werden nur Nachrichten aus dem Kalenderjahr 2026 verarbeitet.
- Markierungen werden im jeweiligen Browser gespeichert und können als JSON exportiert/importiert werden.
- Es gibt noch keine gemeinsame Live-Synchronisierung zwischen Philipp und Lena.

## Nutzung

1. GitHub-Pages-Adresse öffnen.
2. Telegram-JSON-Datei lokal auswählen.
3. Anfang und Ende einer Situation markieren oder Nachrichten direkt einer Situationsnummer zuordnen.
4. Markierungen regelmäßig exportieren.
5. Exportdatei bei Bedarf auf dem zweiten Gerät importieren.

## Umfang

Diese Phase prüft ausschließlich Situationsgrenzen. Inhaltliche Klassifizierung, Musteranalyse und reale Modellaufrufe bleiben gesperrt.
